BMW X5 ONLINE — комнаты до 4 игроков

Что работает:
- Создание комнаты и вход по коду.
- Синхронизация положения/поворота машин между участниками.
- Ссылка комнаты через кнопку «Скопировать ссылку».
- Управление с телефона сохранено.

Запуск на компьютере:
1) Установи Node.js 20+.
2) Распакуй архив, открой терминал в этой папке.
3) Выполни: npm install
4) Выполни: npm start
5) Открой http://localhost:3000

Чтобы играть с друзьями через интернет:
- Размести всю папку на Node.js-хостинге, который поддерживает WebSocket (например, Render/Railway).
- Команда запуска: npm start
- После публикации открой публичный HTTPS-адрес. Друзья заходят по нему и вводят код комнаты.
- Для телефона нужен HTTPS-домен. Локальный localhost доступен только на том же устройстве.

Примечание: это базовый мультиплеерный прототип; другие машины отображаются упрощёнными моделями, не синхронизируются столкновения и физика сервера.
